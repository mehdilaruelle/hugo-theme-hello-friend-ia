{{- /* What a page says about itself, in one place. head.html and json-ld.html used to work it out separately, so a term page with nothing written on it got a description in its meta tag and none in its CollectionPage. Returns the empty string when the page has nothing of its own. The site-wide fallback belongs in description-meta.html, not here: repeating it in the structured data of every page is the duplication this chain exists to avoid. A taxonomy or term page with no summary is described by naming its term. A site with many tags has as many term pages, and the site description on every one makes each look like a copy of the next, which is the one thing they are not -- each holds a different set of posts. */ -}} {{- $description := "" -}} {{- if and .IsHome (not .Description) -}} {{- /* homeSubtitle is the line under the title. A front page with a description of its own says what the site is for at the length a search result gives it, so that wins. */ -}} {{- $description = .Site.Params.homeSubtitle | plainify | htmlUnescape -}} {{- else if .Description -}} {{- $description = .Description -}} {{- else if and (eq .Kind "taxonomy") (not .Summary) -}} {{- /* Through i18n.html rather than i18n: with enableMissingTranslationPlaceholders on, a missing key renders "[i18n] key" rather than the empty string, so the test below never fires and the placeholder is what gets published. */ -}} {{- $description = partial "i18n.html" (dict "key" (printf "taxonomyDescription%s" (title .Data.Singular)) "fallback" "") -}} {{- if not $description -}} {{- $description = partial "i18n.html" (dict "key" "taxonomyDescription" "fallback" "") -}} {{- end -}} {{- else if and (eq .Kind "term") (not .Summary) -}} {{- /* .Data.Singular is Hugo's own word for the taxonomy, so it is English whatever the page is written in. One string per taxonomy instead. */ -}} {{- $description = partial "i18n.html" (dict "key" (printf "termDescription%s" (title .Data.Singular)) "args" (dict "Term" .Data.Term) "fallback" "") -}} {{- if not $description -}} {{- $description = partial "i18n.html" (dict "key" "termDescription" "args" (dict "Term" .Data.Term) "fallback" "") -}} {{- end -}} {{- else -}} {{- /* Google shows about 155 characters and reads none of the rest, so the summary is flattened to one line and cut to a length a result holds. A description written by hand is left as written. htmlUnescape before truncate: plainify strips tags and leaves the entities Goldmark made, so an apostrophe shipped as a literal "’", and a cut could land inside one. TrimSpace rather than chomp, which takes newlines and not the space the flattening made. */ -}} {{- $description = .Summary | plainify | htmlUnescape | replaceRE "\\s+" " " | strings.TrimSpace | truncate 160 "" -}} {{- end -}} {{- return $description -}}
