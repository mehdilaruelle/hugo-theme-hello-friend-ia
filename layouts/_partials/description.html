{{- /* What a page says about itself, in one place. head.html puts it in a meta tag and json-ld.html puts it in structured data, and they used to work it out separately: the JSON-LD read .Description alone, so a term page with nothing written on it got a description in its meta tag and none in its CollectionPage. Returns the empty string when the page has nothing of its own. The site-wide fallback is deliberately not applied here: it belongs in a meta tag, and repeating it in the structured data of every page without a description of its own is the duplication this chain exists to avoid. */ -}} {{- /* A list or taxonomy page has no summary, so the chain used to end in an empty string and the tag shipped as content="". The site description is the same fallback og:description already uses; the tag is dropped entirely when even that is unset, since an empty one says less than none at all. A term page with nothing written on it is given a description naming its term instead. A site with many tags has as many term pages, and the site description on every one of them makes each look like a copy of the next to a search engine, which is the one thing they are not: each holds a different set of posts. A term page that does have a _index.md with a body keeps its own summary, which says more than any sentence generated from the term. */ -}} {{- $description := "" -}} {{- if and .IsHome (not .Description) -}} {{- /* homeSubtitle is the line under the title, written to be read on the page. A front page with a description of its own says what the site is for at the length a search result gives it, so that wins. */ -}} {{- $description = .Site.Params.homeSubtitle | plainify | htmlUnescape -}} {{- else if .Description -}} {{- $description = .Description -}} {{- else if and (eq .Kind "taxonomy") (not .Summary) -}} {{- /* The index of a taxonomy had nothing of its own, so it fell through to the site description and read as a copy of the front page. Same shape as the term branch below: a string per taxonomy, and a generic one for taxonomies the theme does not know. Through i18n.html rather than i18n: with enableMissingTranslationPlaceholders on, a missing key renders "[i18n] key" rather than the empty string, so the test below never fires and the placeholder is what gets published. */ -}} {{- $description = partial "i18n.html" (dict "key" (printf "taxonomyDescription%s" (title .Data.Singular)) "fallback" "") -}} {{- if not $description -}} {{- $description = partial "i18n.html" (dict "key" "taxonomyDescription" "fallback" "") -}} {{- end -}} {{- else if and (eq .Kind "term") (not .Summary) -}} {{- /* .Data.Singular is Hugo's own word for the taxonomy, so it is English whatever the page is written in. One string per taxonomy instead, and a term-only one for taxonomies the theme does not know. */ -}} {{- $description = partial "i18n.html" (dict "key" (printf "termDescription%s" (title .Data.Singular)) "args" (dict "Term" .Data.Term) "fallback" "") -}} {{- if not $description -}} {{- $description = partial "i18n.html" (dict "key" "termDescription" "args" (dict "Term" .Data.Term) "fallback" "") -}} {{- end -}} {{- else -}} {{- /* The summary runs to whatever Hugo decided, newlines and all, and went out whole: 549 characters on the exampleSite, six of its twenty descriptions carrying a line break. Google shows about 155 and reads none of the rest, so it is trimmed to a length a result can hold and flattened to one line. A description written by hand is left exactly as written. */ -}} {{- /* chomp takes newlines and not spaces, and the flattening above turns the summary's trailing newline into one, so the string ended in a space and the tag shipped it. Invisible until something is appended to it, which head.html now does on a pager. */ -}} {{- /* htmlUnescape because plainify strips tags and leaves entities, and Goldmark makes them: an apostrophe in the prose became ’, which the meta attribute escaped again, so the tag shipped a literal "’" for a search engine to read. Before truncate, so a cut can no longer land inside an entity and leave "&rsq" behind. */ -}} {{- $description = .Summary | plainify | htmlUnescape | replaceRE "\\s+" " " | strings.TrimSpace | truncate 160 "" -}} {{- end -}} {{- return $description -}}
