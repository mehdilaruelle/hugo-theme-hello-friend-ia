The menu folds behind the hamburger on a phone, so on the screen where a visitor is most likely to be reading a language that is not theirs, the switcher could not be seen at all. Beside the theme toggle it is there at every width. A details/summary rather than a button and a script. The panel then opens with no JavaScript at all — by pointer, by tap and by keyboard alike, with the open state announced — so a visitor who cannot run the bundle can still leave a page written in a language they do not read. main.js only adds closing it with Escape or a click outside, which is a convenience rather than the way in. Every configured language is listed, the current one included and marked: a globe on its own does not say which language the page is already in. Each entry points at this page's translation where there is one, and at that language's home page where there is not — landing one level up beats a link to a page that was never written. */ -}} {{- if and .Site.Params.EnableGlobalLanguageMenu hugo.IsMultilingual -}} {{- $page := . -}} {{- $label := partial "i18n.html" (dict "key" "language" "fallback" "Language") -}}
