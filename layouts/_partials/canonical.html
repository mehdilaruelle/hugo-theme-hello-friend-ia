{{- /* The URL this page names as its own, and which pager of a list it is. Returns a map with url and pager. Every pager of a paginated list shares one .Permalink, so page 2 and beyond used to name page 1 as their canonical. That tells a search engine they are duplicates of it and their posts are not worth indexing from here, which is the opposite of what pagination is for: each pager is a distinct set of posts, so each is its own canonical. The paginator is only built on the kinds list.html paginates. Building it on a page that is never paginated would build a paginator, and with it the /page/2/ output files, for nothing. In a partial because four templates need this answer: head.html for the canonical link, the hreflang set and the title, opengraph.html for og:url and og:title, and json-ld.html to know whether this is the pager it describes. Working it out in each of them is four templates that will disagree one day, and that is the bug this file was extracted to fix -- og:url named page 1 on every pager while the canonical beside it named the pager itself, so the page claimed to be two different URLs. */ -}} {{- $canonical := .Permalink -}} {{- $pager := 1 -}} {{- if in (slice "section" "taxonomy" "term") .Kind -}} {{- with .Paginate (partial "list-pages.html" .) -}} {{- $canonical = .URL | absURL -}} {{- $pager = .PageNumber -}} {{- end -}} {{- end -}} {{- return dict "url" $canonical "pager" $pager -}}
