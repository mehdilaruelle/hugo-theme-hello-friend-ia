{{- /* The fallback face, as CSS text, for whoever wants to put it somewhere. Inter loads with font-display: swap, so a page is painted in whatever the system offers and repainted in Inter. Two fonts with different metrics take different amounts of room, so that second paint moves everything under the text. Matched metrics make the swap free. The defaults are measured from the font this theme ships, not copied from an article: unitsPerEm 2816, winAscent 2728, winDescent 680 out of static/fonts/Inter-Regular.woff, and Inter measured at 105.39% the width of Arial. .github/scripts/font-metrics.mjs is how they were read, and how to read them again. Which is the catch worth knowing: replace the font files and keep the family name, and these numbers describe a font that is no longer there. Override them, or set params.fontFallback to false to drop the face entirely. See the README. Returns the empty string when the site has turned it off, so the caller can concatenate nothing rather than an empty file. */ -}} {{- $fallback := site.Params.fontFallback | default dict -}} {{- $css := "" -}} {{- if ne $fallback false -}} {{- $sizeAdjust := $fallback.sizeAdjust | default "105.39%" -}} {{- $ascent := $fallback.ascentOverride | default "91.92%" -}} {{- $descent := $fallback.descentOverride | default "22.91%" -}} {{- $lineGap := $fallback.lineGapOverride | default "0%" -}} {{- $local := $fallback.local | default (slice "Arial" "Helvetica" "Liberation Sans") -}} {{- $src := slice -}} {{- range $local -}} {{- $src = $src | append (printf "local(\"%s\")" .) -}} {{- end -}} {{- $css = printf "@font-face{font-family:\"Inter fallback\";src:%s;size-adjust:%s;ascent-override:%s;descent-override:%s;line-gap-override:%s}" (delimit $src ",") $sizeAdjust $ascent $descent $lineGap -}} {{- end -}} {{- return $css -}}
