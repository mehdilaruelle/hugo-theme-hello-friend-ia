{{- /* The picture a social card should show, and how to describe it. Returns a map with url, alt, svg, owned and the picture's size; url is empty when there is nothing to show. One place, because head.html writes the Open Graph tags and twitter_cards.html the Twitter ones, and a card whose two halves disagree shows one picture and names another. Order: the page's images, its cover, the site's images, then ogImage. The site pair is in that order because Hugo's own Open Graph partial reads site images and knows nothing of ogImage, and it is the one emitting og:image when they are set. An SVG is passed over: no platform renders one on a card, so a cover in that format falls through to a fallback that will show. The two keys Hugo also reads are not skipped, because it emits og:image from them whatever the theme decides and the two halves have to name the same file -- svg reports that case so the card is not announced as one with a picture in it. alt describes the picture, so it is only offered for one belonging to this page: the site-wide fallback is the same image everywhere, and this page's title would be true of the article and false of the picture. coverCaption belongs to the cover alone, not to an images[0] that overrode it. owned says which half of the chain answered, because the two are read for different purposes. A card shows whatever picture it is handed and asks no questions of it, so the site-wide fallback belongs there. Structured data is a claim about the subject of this page, and one file asserted as the subject of two hundred articles is worse data than no file at all -- the argument description.html already makes about not repeating the site description in the structured data of every page. json-ld.html reads this key and takes the picture only when the page brought one of its own. */ -}} {{- $img := "" -}} {{- $alt := "" -}} {{- $owned := false -}} {{- with .Params.images -}} {{- $img = index . 0 -}} {{- $alt = partial "title.html" $ -}} {{- $owned = true -}} {{- end -}} {{- if not $img -}} {{- with .Params.cover -}} {{- if ne (lower (path.Ext (urls.Parse .).Path)) ".svg" -}} {{- $img = . -}} {{- $alt = or $.Params.coverCaption (partial "title.html" $) -}} {{- $owned = true -}} {{- end -}} {{- end -}} {{- end -}} {{- if not $img -}} {{- with site.Params.images -}}{{- $img = index . 0 -}}{{- end -}} {{- end -}} {{- if not $img -}} {{- with site.Params.ogImage -}} {{- if ne (lower (path.Ext (urls.Parse .).Path)) ".svg" -}}{{- $img = . -}}{{- end -}} {{- end -}} {{- end -}} {{- /* Resolved as a resource so the URL names a file Hugo wrote; a remote one is left alone. The size comes off the same resource, for og:image:width and og:image:height. Without them Facebook and LinkedIn hold the first render back until they have fetched and measured the file, which is why a freshly shared link so often appears with no picture on it. It is nearly free here, since the resource is already in hand. Only a local file can be asked. The guard is image.html's, for image.html's reason: an SVG reports ResourceType "image" and answers neither .Width nor .Resize, so asking aborts the build -- which is the same fact that makes an SVG unusable on a card, and why the chain above skips one. Where a format will not give its dimensions up Hugo returns 0, and 0 asserted as a width is worse than saying nothing. */ -}} {{- $url := "" -}} {{- $svg := false -}} {{- $width := 0 -}} {{- $height := 0 -}} {{- with $img -}} {{- $svg = eq (lower (path.Ext (urls.Parse .).Path)) ".svg" -}} {{- $url = . -}} {{- if not (partial "is-remote.html" $url) -}} {{- with or ($.Resources.GetMatch $url) (resources.Get (printf "_static%s" $url)) (resources.Get $url) -}} {{- $url = .Permalink -}} {{- if reflect.IsImageResourceWithMeta . -}} {{- if gt .Width 0 -}} {{- $width = .Width -}} {{- $height = .Height -}} {{- end -}} {{- end -}} {{- else -}} {{- $url = urls.JoinPath site.BaseURL $url -}} {{- end -}} {{- end -}} {{- end -}} {{- /* coverCaption is Markdown, and an attribute is text. */ -}} {{- with $alt -}} {{- $alt = . | markdownify | plainify | replaceRE "\\s+" " " | chomp -}} {{- end -}} {{- return dict "url" $url "alt" $alt "svg" $svg "owned" $owned "width" $width "height" $height -}}
