{{- /* The picture a social card should show, and how to describe it. Returns a map with url, alt, svg and owned; url is empty when there is nothing to show. One place, because head.html writes the Open Graph tags and twitter_cards.html the Twitter ones, and a card whose two halves disagree shows one picture and names another. Order: the page's images, its cover, the site's images, then ogImage. The site pair is in that order because Hugo's own Open Graph partial reads site images and knows nothing of ogImage, and it is the one emitting og:image when they are set. An SVG is passed over: no platform renders one on a card, so a cover in that format falls through to a fallback that will show. The two keys Hugo also reads are not skipped, because it emits og:image from them whatever the theme decides and the two halves have to name the same file -- svg reports that case so the card is not announced as one with a picture in it. alt describes the picture, so it is only offered for one belonging to this page: the site-wide fallback is the same image everywhere, and this page's title would be true of the article and false of the picture. coverCaption belongs to the cover alone, not to an images[0] that overrode it. owned says whether the picture is the page's own, and json-ld.html takes it only then. A card shows whatever it is handed, so the site-wide fallback belongs there; structured data is a claim about the subject of this page, and one file asserted as the subject of two hundred articles is worse data than no file. alt and owned are set from $img rather than beside it, because an entry that is present but empty -- images = [""], which the README's own sample ships -- passes `with` and then falls through to the site's picture. */ -}} {{- $img := "" -}} {{- $alt := "" -}} {{- $owned := false -}} {{- with .Params.images -}} {{- $img = index . 0 -}} {{- end -}} {{- with $img -}} {{- $alt = partial "title.html" $ -}} {{- $owned = true -}} {{- end -}} {{- if not $img -}} {{- with .Params.cover -}} {{- if ne (lower (path.Ext (urls.Parse .).Path)) ".svg" -}} {{- $img = . -}} {{- $alt = or $.Params.coverCaption (partial "title.html" $) -}} {{- $owned = true -}} {{- end -}} {{- end -}} {{- end -}} {{- if not $img -}} {{- with site.Params.images -}}{{- $img = index . 0 -}}{{- end -}} {{- end -}} {{- if not $img -}} {{- with site.Params.ogImage -}} {{- if ne (lower (path.Ext (urls.Parse .).Path)) ".svg" -}}{{- $img = . -}}{{- end -}} {{- end -}} {{- end -}} {{- /* Resolved as a resource so the URL names a file Hugo wrote; a remote one is left alone. */ -}} {{- $url := "" -}} {{- $svg := false -}} {{- with $img -}} {{- $svg = eq (lower (path.Ext (urls.Parse .).Path)) ".svg" -}} {{- $url = . -}} {{- if not (partial "is-remote.html" $url) -}} {{- with or ($.Resources.GetMatch $url) (resources.Get (printf "_static%s" $url)) (resources.Get $url) -}} {{- $url = .Permalink -}} {{- else -}} {{- $url = urls.JoinPath site.BaseURL $url -}} {{- end -}} {{- end -}} {{- end -}} {{- /* coverCaption is Markdown, and an attribute is text. */ -}} {{- with $alt -}} {{- $alt = . | markdownify | plainify | replaceRE "\\s+" " " | chomp -}} {{- end -}} {{- return dict "url" $url "alt" $alt "svg" $svg "owned" $owned -}}
